# Project Documentation Rules (Non-Obvious Only)

- `scripts/ibmi-deploy.sh` and `scripts/ibmi-compile.sh` are the single source of truth for compile commands and upload steps — not `docs/DEPLOY.md`, which is a human-readable guide that points at those scripts rather than a spec of its own. The dependency order the scripts (via `Rules.mk`) build in is: TODOPF → TODOLF → TODODSPPF → TODOBL.MODULE → TODOBL.SRVPGM → TODOBND.BNDDIR → TODOMAIN.PGM. See [AGENTS.md](../../AGENTS.md#compile-commands) for the full story of why the script does more than a single `makei build`.
- The indicator map exists in **two places**: `QDDSSRC/TODODSPPF.DSPF` header and `QRPGLESRC/TODOMAIN.RPGLE` header — both must be updated together when indicators change.
- `QDDSSRC/TODOLF.LF` references the physical file as `PFILE(*CURLIB/TODOPF)` — resolves to whichever library is current for the compiling profile, not a hardcoded name (pub400.com restricts library creation).
- There is no automated test run today, but there is test *source*: `QRPGLESRC/TODOTEST.RPGLE` exists and targets `TODOBL`'s exported procedures via RPGUnit conventions (`setUp`, `tearDown`, `testGetNextId_WithRecords`, `testGetNextId_NoHigherRecord`, `testValidateDescription_Blank`, `testValidateDescription_Spaces`, `testValidateDescription_Valid`, `testAddTodoRecord`, `testMarkDoneRecord`). It cannot currently build or run because RPGUnit is not installed on this pub400 profile (see AGENTS.md's RPGUnit note) — not a priority to fix. There is also no linter. Correctness today is verified by compiling on the IBM i server and inspecting the job log / `.evfevent` diagnostics.
